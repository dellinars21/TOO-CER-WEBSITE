# Басты бет | ТОО «Caspian Engineering & Research»

#### «Caspian Engineering & Research» ЖШС, Қазақстанның мұнай және газ секторындағы жетекші инжинирингтік компанияларының бірі, 2003 жылы 29 тамызда құрылған және Қазақстан Республикасы Әділет Министрлігінің Маңғыстау облыстық Әділет Департаментінде тіркелген, № 5727-1943-ТОО.

Ұсынылған қызметтерді атқару мақсатында компанияда мұнайгаз саласындағы нысандарды жобалауға, табиғатты қорғауды зерттеуге, тау кен, мұнай химиялық, химиялық өндіріс нысандарын жобалауға, жер асты құрылыстарын, ыдыстар мен құбырларды жобалауға қажетті барлық лицензиялар қолда бар.
