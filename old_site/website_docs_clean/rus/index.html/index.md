# Главная | ТОО «Caspian Engineering & Research»

#### ТОО «Caspian Engineering & Research», одна из ведущих инжиниринговых компаний в нефтегазовом секторе Казахстана, учреждена и зарегистрирована в Департаменте юстиции Мангистауской области Министерства юстиции Республики Казахстан 29 августа 2003 г., № 5727-1943-ТОО.

Для реализации предлагаемых услуг компания имеет все лицензии, необходимые для выполнения работ, связанных с проектированием объектов нефтегазовой отрасли, с природоохранным проектированием, с проектированием горных, нефтехимических, химических производств, подземных сооружений, сосудов и трубопроводов.
